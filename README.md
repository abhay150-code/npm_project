# Student Management Portal & REST API

An interactive Student Management Web Application & REST API built with **Node.js** and **Express.js**.

This project provides a complete practical demonstration of the [`@abhay150/express-error-kit`](https://www.npmjs.com/package/@abhay150/express-error-kit) NPM package for centralized error handling, request tracking, and async safety.

---

## 🔍 How to Check if `@abhay150/express-error-kit` is Working

You can verify that your published NPM package is installed and actively functioning in this project using any of these 4 methods:

### Method 1: Check Installation via NPM CLI
Run this command in the `student-management-api` directory:
```bash
cd student-management-api
npm list @abhay150/express-error-kit
```
**Expected Output:**
```text
student-management-api@1.0.0
└── @abhay150/express-error-kit@1.0.0
```
This confirms that the actual published package is resolved from `node_modules`.

### Method 2: Verify Package Exports with Node.js
Run this one-liner to verify that Node loads the package and see all its exported modules:
```bash
cd student-management-api
node -e "
const kit = require('@abhay150/express-error-kit');
console.log('Installed Location:', require.resolve('@abhay150/express-error-kit'));
console.log('Exported APIs:', Object.keys(kit));
"
```
**Expected Output:**
```text
Installed Location: .../node_modules/@abhay150/express-error-kit/src/index.js
Exported APIs: [
  'AppError',
  'NotFoundError',
  'ValidationError',
  'UnauthorizedError',
  'ForbiddenError',
  'ConflictError',
  'asyncHandler',
  'errorHandler',
  'requestId'
]
```

### Method 3: Verify in Action via Terminal / curl
Check that both **`requestId` middleware** and **`errorHandler`** are actively working:

1. **Verify Request ID tracking:**
   ```bash
   curl -i http://localhost:3000/health
   ```
   Notice the header injected by your package:
   ```http
   X-Request-Id: 527fa45d-b4f2-405a-8d11-ecec6b865334
   ```

2. **Verify Error Interception and Formatting:**
   ```bash
   curl -s http://localhost:3000/students/non-existent-id
   ```
   Output formatted by your package:
   ```json
   {
     "success": false,
     "message": "Student with ID 'non-existent-id' not found",
     "statusCode": 404,
     "requestId": "e2a3b4c5-6789-4000-8000-123456789abc"
   }
   ```

### Method 4: Test via the Web Dashboard
1. Start the server (`npm start` inside `student-management-api`).
2. Open **`http://localhost:3000`** in your browser.
3. Scroll to the **"🧪 express-error-kit Live Showcase"** section.
4. Click any button (**ValidationError**, **ConflictError**, **NotFoundError**, etc.).
5. Inspect the live JSON output and `requestId` generated by your package in real-time.

## What's New & Useful

1. **Interactive Web Dashboard (`http://localhost:3000`)**:
   - Zero-framework, lightweight frontend (pure HTML5 / CSS3 / Vanilla JavaScript).
   - Real-time KPI summary cards (Total Students, Active Enrollments, Average GPA, Unique Courses).
   - Instant live search by name or email, plus filter dropdowns by course and status.
   - Modal interface for adding and updating students.
   - **`express-error-kit` Live Showcase**: Interactive test buttons that let you trigger and inspect live `ValidationError` (400), `ConflictError` (409), `NotFoundError` (404), and `AppError` (502) responses directly in the UI.

2. **Expanded Error Handling Capabilities**:
   - Demonstrates **`ConflictError`** (HTTP 409) for duplicate email registrations.
   - Demonstrates **`ValidationError`** (HTTP 400) for missing fields, malformed emails, and invalid GPA ranges.
   - Demonstrates **`NotFoundError`** (HTTP 404) for missing IDs and unknown routes.
   - Demonstrates **`requestId`** middleware automatically tagging every request with `X-Request-Id`.
   - Demonstrates **`asyncHandler`** protecting all asynchronous Express routes.
   - Demonstrates **`errorHandler`** formatting standard production-ready JSON responses.

3. **Analytics & Diagnostics**:
   - `GET /health`: Healthcheck endpoint with server uptime and request ID tracking.
   - `GET /students/stats`: Returns student count, GPA averages, and course breakdowns.

## API Endpoints Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Serves the interactive Student Management Web Dashboard |
| `GET` | `/health` | System health check and uptime stats |
| `GET` | `/students` | Get all students (supports `?search=`, `?course=`, `?status=`, `?sortBy=`, `?order=`) |
| `GET` | `/students/stats` | Aggregated analytics (counts, course distribution, average GPA) |
| `GET` | `/students/:id` | Get student details by ID (throws `NotFoundError` if not found) |
| `POST` | `/students` | Create student (throws `ValidationError` or `ConflictError`) |
| `PUT` | `/students/:id` | Update student details (validates email uniqueness & fields) |
| `DELETE` | `/students/:id` | Delete student by ID |
| `GET` | `/students/test-error/:type` | Trigger test errors (`validation`, `conflict`, `not-found`, `app-error`) |
